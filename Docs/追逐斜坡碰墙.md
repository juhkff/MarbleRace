# 追逐斜坡碰墙

`关卡-追逐斜坡` 蓝图中的 `WallResponse`（弹珠碰墙反弹）组件只绑定 `墙`、`墙1` 两个子 Actor 的碰撞网格。其它墙、斜坡和关卡不使用此响应，共用物理材质也不修改。

弹珠撞到墙的侧面后，立即清除角速度，反弹速度取碰墙前水平速度的 20%，限制在 80～400 cm/s，沿墙速度保留 25%。重力和后续正常滚动继续生效。静止接触不额外反弹，同一弹珠 0.12 秒内的重复碰撞通知不重复触发。

打开该蓝图，选择 `WallResponse`，在“碰墙”分类中可调整反弹比例、最小/最大反弹速度、沿墙速度保留比例，也可以关闭“启用碰墙反弹”。

地图中已放置的关卡实例可能保留旧的属性覆盖。检查该实例的 `WallResponse`，“墙组件名称”应同时包含 `墙` 和 `墙1`；只勾选启用但列表为空不会生效。运行 PIE 时，“碰墙|调试”中的“已绑定墙壁数量”应为 2，碰墙后“已触发反弹次数”会增加。

验证：`MarbleRace.Walls.LocalBounceAndSpin` 使用实际弹珠的物理碰撞，检查反弹和自转清除，并检查左右方向、速度上限、重复通知、关闭功能、非目标墙隔离及物理材质保持。

`MarbleRace.Walls.ChaseMapBindings` 直接检查 `MainContent` 地图中已放置的追逐斜坡实例，确保两个墙绑定实际保存且能解析到墙组件。
