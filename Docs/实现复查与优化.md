# Marble Race Simple 参考复查与第一轮优化

## 范围与证据

本轮核对现有源码、交接第 10 节、已有视频抽帧；B 站链接能取得标题，但本轮没有重新解码整段视频或试听音轨。参考人物头像、姓名和 BGM 是后期包装，本项目将其内置；不将其称为原游戏原生功能。

当前关卡是 `/Game/Maps/NewMap`，编辑器查询得到一个导演、一个滚筒、一个终点检查点，以及静态网格赛道。没有删除、重建或保存覆盖地图，也没有修改材质、角色存档或音乐播放器。

## 本轮确认的问题与处理

| 问题 | 影响 | 处理 |
|---|---|---|
| 导演逐球立即提交成绩 | 同帧冲线由数组顺序决定冠军，而不是穿线时刻 | 收集本帧冲线事件后统一排序提交 |
| UE 默认样条有两个沿 X 方向的点 | 未编辑样条也被认作路线，领跑和镜头可能按横向位置判断 | 识别引擎默认占位样条，退回原有线段估算；不清除用户样条 |
| 同帧跨多门未校验时间顺序 | 可以接受在更早时刻经过的后续门 | 校验交点 alpha 单调 |
| 暂停通过清零速度、关闭模拟实现 | 暂停改变比赛轨迹，恢复倒计时可提前解冻，滚筒仍在转 | 使用世界暂停，保留模拟状态与速度，同时暂停现有音乐组件 |
| 结束检查只在完赛回调发生 | 空场或最后选手出界后不会进入结果 | 每帧统一检查剩余有效选手；出界不编造名次 |
| 独立角度扰动导致开局球重叠 | 释放瞬间可能产生穿透解算弹飞 | 等间距槽位、共享相位扰动、随机身份槽位；明确容量限制 |
| 脚本球和滚筒旋转方向相反 | 看起来像装饰动画，运动不一致 | 统一角度符号 |
| 重置/开转重新启用了可视环网格碰撞 | 凸包可能填满环内部，与分段碰撞重复 | 可视网格始终无碰撞，仅分段环壁负责碰撞 |
| 头像 DrawTexture 后画圆框 | 方形图片四角仍可见，不是真正圆裁切 | UV 三角扇只绘制圆内部分 |
| 离屏姓名、没有 GO、结果省略提示覆盖最后一行 | 观赛与结果呈现不完整 | 视口裁剪、开赛 0.8 秒 GO、独立省略行 |
| 镜头前视距离固定为世界单位 | 横屏/矮窗口容易把目标推到画面边缘 | 按实际宽高比限制前视距离至可见高度的 1/4 |

以上为局部修复，不等于已还原完整参考玩法。编译与测试结论见交接记录。

## 仍然决定体验差距的内容

1. **关卡节奏**：旋转圆弧、拨板腔体、周期闸口和受控反弹末段尚未组成参考中的复杂路线。静态坡道链不能替代这些机关。
2. **卡球**：此前交接实测顶部两块水平平台会滞留球。本轮没有暗中倾斜、删除平台或传送球；应先针对这两块平台选择导流坡度或出口尺寸，再做多局完赛率测试。
3. **路线标定**：一个终点检查点只验证终点，不能验证复杂折返/分支是否合法。必须在新增模块出口设置有序检查点及真正编辑过的路线样条。
4. **开局**：倒计时仍是脚本约束球围环旋转，不是真实物理搅拌。等间距放置仅在滚筒容量足够时安全，不应宣称支持 50–60 人无重叠。
5. **完整成绩表**：目前只展示前 10 名和总人数；数十人模式仍需可滚动/翻页列表。
6. **素材和声音**：真实头像、主题曲由用户提供；没有试听不能宣称音频听感通过。

## 建议下一阶段

先在保留原关卡的前提下处理两块卡球平台，验证 8–12 人可完成比赛；再做独立机关测试场，验证旋转拨板与反弹表面真实碰撞、速度上限、可放行性。随后逐段接入原关卡和有序路线，最后扩至 50–60 人及 30/60/120 FPS 压力测试。不要先堆装饰或拉长静态斜坡来假装还原节奏。
