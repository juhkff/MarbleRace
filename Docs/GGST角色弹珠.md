# GGST 角色弹珠

默认名单包含截至 2026-10-02 官方角色页面列出的 **34 位可玩角色**，包含 Lucy、Jam 和 Robo-Ky。

GGST 是可选的本地主题包：`SourceAssets/GGST/`、`Content/GGST/Portraits/`、`Content/GGST/Music/` 和 `Config/GGST/` 均不提交到 Git。没有安装该包的新克隆项目使用 `Config/Roster/default_roster.json` 中的通用彩色弹珠名单，已有本地素材和存档保持可用。通用配置格式见项目根目录的 `README.md`。

- `SourceAssets/GGST/Portraits`：官方下载的原始头像，306×306 或 306×305，未改动角色图。
- `SourceAssets/GGST/Portraits/Cropped`：从原先下载的头像重新裁切 Ky、Zato，保留原来的角色画面和黑色背景。其余角色使用原版头像。`SourceAssets/GGST/portrait_crops.json` 记录裁切矩形，运行 `Scripts/prepare_ggst_portraits.py` 可重新生成；游戏仍使用统一材质，没有额外的角色 UV 参数。
- 裁切后在 UE Python 环境运行 `Scripts/import_ggst.py --portraits-only --characters=kyk,zat` 更新这两张头像，不重新导入音乐。
- `SourceAssets/GGST/Music`：34 首完整 MP3，保留原始音频。
- `Content/GGST/Portraits`：UE Texture2D 头像资源。
- `Content/GGST/Music`：UE SoundWave 音频资源，已设置循环播放。
- `Content/GGST/Materials/M_GGSTMarble`：不透明、无光照的角色弹珠材质。
- `Config/GGST/roster.json`：默认名单、sRGB 色值、图片/音频路径、来源页面、曲名、时长和 SHA-256 校验值。

材质按圆盘本地 XY 坐标投影头像，避免圆盘网格的原有 UV 拉伸。外缘约 9% 为角色专属色；图片透明部分与底色混合，材质仍为 Opaque。`HasPortrait=0` 时显示完整色盘。

姓名由 `AMarbleRaceHUD` 在屏幕空间绘制，使用世界 Z 上方偏移；名称保持水平、固定屏幕字号，不继承弹珠物理旋转。领跑者变更时直接切换主题曲，不做淡入淡出。每个角色在本场比赛中独立记录播放进度，再次领跑时从断开处继续；默认模式下，未播放期间进度不前进，播完后从头循环。倒计时期间不播放，比赛退出时停止；新一场比赛首次播放使用各角色配置的起点，默认 0 秒。

比赛中按 **L** 锁定当前 BGM，领跑角色变化或暂时没有领跑者都不会切歌；按 **U** 解锁，并立即检查当前领跑者。领跑者没变时继续播放，不重新触发。锁定只影响音乐，不影响镜头和参赛角色；每场比赛初始为解锁状态。锁定时左下角显示直径 5 像素的小红点，解锁后消失，不显示文字。

主菜单的 **游戏设置** 提供“按键设置／显示设置／音频设置／录制设置”导航。按键页列出锁定 BGM 的 L 键和解锁 BGM 的 U 键；设置采用左侧名称、右侧启用／禁用的布局，悬停时显示简短说明。偏好自动保存到 `GameUserSettings.ini`；为兼容已有姓名偏好，继续使用 `[MarbleRace.OtherSettings]` 节。

- **稳定名称显示**（默认关闭）：开启后使用不随弹珠旋转变化的姓名高度，并平滑屏幕上的细小抖动；大幅跳变和长帧会直接跟上。关闭时沿用原来的姓名显示代码。
- **终点慢动作**（默认开启）：领跑者距离终点不超过 2000 cm、按当前下落速度预计 0.65 秒内冲线时触发。根据剩余距离与速度动态调整世界时间膨胀，目标将冲线前的一段延长为约 2.4 秒真实时间。每位接替的领跑者有自己的时段；每颗弹珠最多触发一次。冲线、无领跑者或退出比赛时恢复原来的世界速度。计时使用真实时间，BGM 为 UI 音频，音高倍率为 1，保持正常速度。已经在同一物理帧内同时越线的角色无法通过事后的慢动作分开。
- **倒计时缩放过渡**（默认开启）：以正常视野的 60% 开始，使用平滑曲线在 1.8 秒内拉远到正常视野；短于 3 秒的自定义倒计时会相应缩短过渡。正交镜头调整 OrthoWidth，透视镜头调整 FOV，倒计时结束或退出比赛时恢复正常视野。

角色设置采用左侧名单与右侧“基本信息／头像／主题曲”页签，长文本按实际字体宽度截断，头像和音乐列表按面板高度分页。

## 领跑、出生和赛后音乐

当前镜头跟随的弹珠冲线后，连续追赶下一颗尚未完赛的领先弹珠，速度与剩余距离成正比：v = k × 距离。距离越远移动越快，接近目标自动减速，避免瞬移和越过目标。比赛关卡模式“镜头”分类提供“过线镜头追赶系数”，默认 k = 12 /秒；追赶阶段不受普通跟随的固定速度上限和终点慢动作影响，进入目标附近（正常视野宽度的 10%）后恢复普通跟随。采用指数积分实现该线性速度关系，保持不同帧率下的追赶速度一致。多颗同时冲线时一并排除；暂时没有可跟随弹珠时镜头停留，待下一颗可用时继续追赶。全部完赛后保持最后的镜头位置。普通超越、滚动跟随与重定位仍沿用原有平滑跟随。

进入重定位队列时确定该球的下一次世界空间落点。隐藏中的弹珠使用该落点参与领跑与镜头计算，不使用隐藏前的位置或管理器位置；排队期间不判定冲线。轮询、入口编号以及关卡坐标转换均沿用原管理器逻辑；查询排名不会抽取随机位置或推进索引。成功放出使用已经计划的落点。随机出口被挡时，放出检查可以重新计划下一次尝试的位置，保留原先避开出口阻塞的能力。

开局使用每场独立的新随机种子，在滚筒的 X/Z 圆形范围中随机取点，通过重叠检查保持球间间距。参赛名单先随机打乱，不再按角色顺序固定分配网格位置；只有一颗球时也随机生成。场地不足以容纳全部弹珠的极端情况下，取候选中间距最大的随机点。

音频设置中的 **统一 BGM 响度** 默认开启。`Scripts/analyze_ggst_loudness.py` 用 FFmpeg 测量 34 首原始完整曲目并生成 `Config/GGST/music_levels.json`；原始整体响度为 -16.01 至 -4.76 LUFS，统一到 -18 LUFS，同时将真峰值保持在 -1 dBTP 以下。运行时调整播放倍率，原始 MP3 和 UE 音频资源均不改写；比赛和菜单试听共用同一校准，歌曲内部的动态仍然保留。自定义且未测量的歌曲保留原倍率。

**赛后播完当前 BGM** 默认关闭。开启后，最后一颗弹珠冲线时继续播放当前歌曲的剩余部分，至本轮歌曲结尾停止，不重新循环；L/U 不会打断已经进入赛后阶段的歌曲。退出比赛立即停止。关闭时最后一颗弹珠冲线便停止 BGM。

音频设置中的 **后台播放 BGM** 默认关闭。开启后，以倒计时结束、滚筒消失的开赛时刻为共同起点，各参赛角色歌曲从 0 秒持续推进，仅领跑角色的歌曲可听到；尚未领跑、暂时无人领跑和 L 锁定期间，其他歌曲的进度也继续前进。每首歌按自己的时长从头循环，忽略玩家设置的首次播放起点。进度使用不受慢动作影响的真实时间，运行时按同步进度播放当前可听的歌曲，静音歌曲无需同时解码。L/U 仍保持原有锁定与立即解锁检查的行为；赛后续播仍只播完当前可听歌曲的这一轮。关闭后使用原有的首次播放起点和断点续播方式，不改写玩家保存的起点。

## 自动录制比赛

录制设置中的 **自动录制比赛** 默认关闭。开启后从进入比赛场景、倒计时开始录制，包含游戏视口、姓名、倒计时、小红点与游戏音频，不采集桌面或麦克风。最高按源画面输出 1920×1080、30 FPS H.264/AAC MP4，保持画面比例。暂停、慢动作和低帧率时使用真实时间戳，低帧率画面重复补帧，不加速视频。

录制包含赛后的排行榜，正常返回主菜单时结束录制并在后台编码。比赛中按 **ESC** 强制中断并返回主菜单，同时丢弃本场录制；此前已保存的录像保留。每场比赛单独生成一个 MP4，文件名包含时间和随机编号。游戏退出时等待当前编码完成。视频位于 `Saved/Recordings`，可从设置页打开文件夹。临时 JPEG 与声音只在成功生成 MP4 或主动丢弃本场录制后删除；编码失败时保留以便恢复，并在设置页与日志中说明原因。FFmpeg Windows 编码工具与许可位于 `Tools/FFmpeg`，打包时作为 NonUFS 文件一起发布。录制需额外的 GPU 回读、CPU 与临时磁盘空间。

录制区域取摄像机实际显示区域，排除宽屏窗口两侧的黑边；图像与游戏声音使用同一真实时间基准，避免慢动作和编码排队造成音画偏移。

## 冲线与排行榜

每颗弹珠冲线时，在屏幕中上方显示约 2 秒的名次与角色名称。全部冲线后显示角色、歌名和比赛用时，歌名使用角色名称下方的小字。用时从倒计时结束开始计算，不受终点慢动作影响；同一帧冲线的弹珠按估算的实际过线时刻排序。

排行榜按每页 10 名顺序展示，每页停留 5 秒，最后一页结束后自动返回主菜单；“继续”按钮可提前返回。排行榜停留时间使用真实时间，录制持续至返回主菜单。

“主题曲”页可以播放／暂停试听，并点击或拖动时间条定位。拖动时暂停音频，释放后恢复之前的播放状态。首次播放起点可以输入秒数并按回车或点击“保存”，也可以点击“设为当前时间”使用试听位置；“归零”恢复从头播放。设置按角色自动保存，超过曲长的输入会限制到歌曲结尾之前。该起点只用于每场比赛中角色首次触发 BGM，后续续播与从头循环不受影响；试听不改变比赛进度。切换角色、退出主题曲页或离开菜单时停止试听。更换歌曲时起点恢复为 0 秒。

“弹性三角2”的“跳板弹射”组件提供“弹射冷却时间”，默认 2 秒。同一颗弹珠在成功弹射后的冷却时间内不能再次弹射，其余弹珠独立计时；被忽略的碰撞不会延长冷却。使用游戏时间，暂停或慢动作时随场景变化，退出比赛后清空记录。其它跳板保留原来的 0.15 秒间隔。

安装了 GGST 本地名单时，首次读取旧版名单先将完整旧存档备份到 `Saved/SaveGames/MarbleRaceRoster_PreGGST.sav`，再保存 GGST 名单；没有安装时保留旧版名单。后续会继续读取玩家编辑后的新名单，不会每次开赛重置。名单配置在本地存在时由模块的 RuntimeDependencies 以 UFS 方式打包，`/Game/GGST` 整个资源目录会参与烘焙。通用模板始终打包，GGST 配置和录制工具缺失不会导致构建或暂存失败。

原始角色图来自 [GGST 官方角色页](https://www.guiltygear.com/ggst/en/character/)；33 首曲目来自用户提供的 [网易云 GGST 电台](https://music.163.com/djradio?id=962855155)。Lucy 是联动角色，没有独立的 GG 原创主题曲，本项目选用联动曲目《I Really Want to Stay at Your House》，来自 [网易云公开电台节目](https://music.163.com/dj?id=2515399150)，与 [官方 1.48 更新中的联动曲目列表](https://www.guiltygear.com/ggst/kr/news/post-2536/) 核对。Jam 的主题曲是《Trying hard is hard, so I try hard to try hard.》，《Master of your own soul》是游戏 2.0 的主题曲，不属于角色曲。

## 更新与验证

使用带 Pillow 的 Python 运行 `Scripts/download_ggst.py` 下载并核对来源；无需登录，也不使用账号 cookie。脚本会检查官方角色名单和曲名，角色增减或不匹配会明确报错。

在 UE Python 环境运行 `Scripts/import_ggst.py` 导入资源。已经存在的素材会复用，头像来源文件或音频时长改变时重新导入。只有材质不存在时自动构建材质图；主动重建图时使用 `--rebuild-material` 并在完整编辑器中执行。

运行 `Scripts/validate_ggst_sources.py` 检查原始文件哈希、数量、颜色唯一性和资源路径。UE 自动测试 `MarbleRace.GGST.CompleteRosterAndAssets` 验证默认名单、头像加载、完整音频时长、循环状态及不透明材质；验证过程不修改用户存档。
