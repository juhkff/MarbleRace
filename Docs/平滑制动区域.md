# 平滑制动区域

资产：`/Game/赛道组件/平滑制动区域`。可直接拖进地图，也可在关卡蓝图中添加子 Actor 并选用此资产。

将盒子覆盖需要减速的中点之前的一段轨道，而不是只覆盖中点一条线。选中“制动范围”组件调整 Box Extent，或调整 Actor 的缩放与旋转。盒子的 Y 厚度要覆盖弹珠所在的侧视平面。避免两个制动区域重叠，否则制动力会叠加。

默认参数：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| 目标小速度 | 50 cm/s | 低于此速度不施加线性制动力，不主动加速 |
| 制动强度 | 30 | 超出目标速度越多，制动越强 |
| 最大制动加速度 | 8000 cm/s² | 限制高速球刚进入时的减速力度 |
| 边缘渐变距离 | 100 cm | 从盒子边缘向内逐渐增强制动 |
| 制动力过渡时间 | 0.15 s | 进入和离开时平滑过渡 |
| 同步制动旋转 | 开启 | 连续施加反向力矩，避免旋转重新带快弹珠 |
| 旋转制动强度 | 20 | 旋转减速力度 |

整个过程使用 AddForce / AddTorqueInRadians，不调用设置速度，也不修改重力、恢复力或碰撞设置。质量不同的弹珠得到相同的制动加速度。旋转目标按目标小速度除以当前弹珠半径计算。

重力持续加速时，实际稳定速度会略高于目标：沿运动方向的加速度约为 980 cm/s²、制动强度为 30 且区域权重为 1 时，理论稳定速度约为 83 cm/s。区域越窄、边缘渐变占比越大，弹珠能接受的制动时间越短，因此无法保证经过某一坐标时必定等于目标速度。

调节顺序：先把区域起点放到中点前足够远的位置，让球在到达中点前减速；若仍太快，扩大区域或提高制动强度及加速度上限；若减速太猛，降低加速度上限或增加过渡时间。高速球从 1500 cm/s 减到 50 cm/s，在最大加速度 8000 cm/s² 下仅按恒定最大制动估算就需要约 140 cm，实际还需留出渐变和低速收尾的距离。

隐藏等待重定位、暂停物理、销毁的弹珠会从当前区域的制动记录中清理，不共享其他弹珠的过渡进度。离开区域后反向力会短暂平滑衰减；关闭“启用制动”会立即停止该区域的制动。
